# R2 feasibility preflight (before lock)

- External benchmark: AlloBench repository snapshot, 2,257 PDB-level records, 429 targets, 2,146 PDB IDs, curated allosteric-site residues and active-site residues. Source repository and paper URLs are recorded. The repository states its records derive from ASD, UniProt, and RCSB PDB. ASD's own bulk file requires registration and forbids redistribution; therefore this round uses the openly licensed AlloBench derived table and fresh RCSB coordinates, not restricted ASD bulk files.
- Independence: all 15 R0 PDB entries and their seven UniProt proteins will be excluded before sampling.
- Tractability: use one lexicographically first passing PDB per AlloBench target; cap at 80 targets after deterministic sorting. ESM2-8M embeddings were already feasible for 15 proteins in R0. Structure graph and residue features are linear/quadratic only within each chain and feasible on CPU.
- Family control: cluster benchmark sequences at 30% global identity by deterministic single-linkage using parasail if available, otherwise Biopython pairwise alignment. The protocol requires at least 8 families with >=2 proteins and 30 total proteins. If infeasible, stop before modeling.
- Conservation: within-family column conservation from deterministic global multiple alignment is only valid in families with >=3 sequences. Proteins without a valid family alignment receive a missing indicator and training-fold median imputation. This is weaker than evolutionary-profile conservation and will be labeled accordingly.
- Geometry/network: C-alpha contact graph at 8 Å; degree, closeness, betweenness, local clustering, residue depth proxy (distance from chain centroid), and secondary-structure proxy from backbone geometry. No ligand coordinates enter features.
- External pathway endpoint: AlloBench active sites provide an independent endpoint. Shortest graph paths between curated active and allosteric sites define pathway corridors; endpoint is enrichment of model scores on intermediate corridor residues versus matched non-site residues. This is a structural corridor proxy, not experimentally measured dynamics.
- Compute ledger: wall time, peak RSS, package versions, model identifier, and artifact hashes will be recorded per stage.
