# R2 Project Summary - Universal Confounder Stress Test

## Verdict
Useful pre-outcome specification negative. All three fresh source gates passed, but the locked prose did not freeze an executable configuration/dimension implementation. No endpoint model performance was inspected.

## Useful discovery
Heart, HAR and molHIV are feasible under the stated source/unit gates, including 19,083 molHIV scaffolds with pinned RDKit/OGB. Yet the supposed unchanged detector could not be reproduced without inventing hyperparameters, configuration rows, dimension equations, seeds and control mechanics. Universal scoring is therefore closed for R2.

## Why it matters
Semantic preregistration can still leave outcome-driving degrees of freedom. A grant-grade validation auditor needs an executable, hashed configuration registry, not thresholds in prose alone.

## Application
The retained fail-closed dossier validator checks schema, protocol hash, dimensions, ranges and provenance. It is review support only. It does not score validation risk because the frozen dimension implementation is incomplete.

## Next experiment
R3 must lock a versioned executable config before endpoint inspection, then use independent teams for specification, blinded execution and reproduction. Same sources may be reused because no R2 endpoint was opened, but R3 must be labeled a new protocol rather than unchanged R2.
