# Prior-art screen: October 7, 2026

Conclusion: these kernels are implementations of established constrained and
robust shortest-path ideas, not algorithm inventions. Combining a deterministic
resource constraint and scenario-vector costs does not establish novelty.
No superiority over any paper has been measured. This screen is not exhaustive.

Fetched sources:

- Gzara and Lu (2018), Models and algorithms for the robust resource constrained
  shortest path problem. Publisher-hosted preprint abstract describes robust
  RCSPP and modified label setting with dominance rules.
  https://optimization-online.org/2018/03/6519/
- Raith et al. (2018), Extensions of labeling algorithms for multi-objective
  uncertain shortest path problems. Full publisher page discusses generic
  labeling, finite common scenarios and minmax robustness.
  https://onlinelibrary.wiley.com/doi/10.1002/net.21815
- Multi-objective minmax robust combinatorial optimization with
  cardinality-constrained uncertainty. Preprint HTML describes label setting,
  robust optimization and conservative cycle costs. The cardinality-constrained
  uncertainty set is not identical to this implementation's finite scenario set.
  https://ar5iv.labs.arxiv.org/html/1701.06317
- Robust and Distributionally Robust Shortest Path problems: A survey (2025).
  Publisher/index page abstract identifies a broad literature, including exact
  methods for robust paths with scenarios. Not a full-text replication.
  https://dlnext.acm.org/doi/10.1016/j.cor.2025.107096
- RePEc bibliographic record for the cardinality-constrained paper, corroborating
  publication details. This is the same work as the preprint, not independent
  evidence for a separate algorithm.
  https://ideas.repec.org/a/eee/ejores/v267y2018i2p628-642.html
- A parallel pull labelling algorithm for the resource constrained shortest path
  problem (2025), indexed publication excerpt. Describes label buckets,
  bidirectional search and vectorized dominance. Not a reproduced baseline.
  https://exa.ai/library/publication/s5zqxzhvdtt

Evidence types: publisher full-text/abstract, preprint HTML, bibliographic record,
and indexed publication excerpt. The six URLs include one duplicate work.
Any reported speedup in these pages is the authors' claim, not our result.

Next invention work should target a defined gap after an anatomy-specific
literature review, not rename these algorithms. Real data availability and
physiological calibration are still unresolved.
