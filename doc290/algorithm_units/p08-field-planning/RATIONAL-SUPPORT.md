# Exact rational separating support

Restricted established terminal reachability math, not invention. Fraction arithmetic
computes saturated-ramp support values and witness schedules from exact supplied
integer/Fraction/rational-string data. Floats and bools refused: decimal strings
mean exactly those decimals, not measurement accuracy. A strict target projection
outside the exact interval proves unreachable for this exact abstract model.
Nonseparation in one or finitely many directions does NOT prove joint feasibility.

45 local dev methods pass (41 + 4): exact boundary and extremely small positive
separation, rank-one joint separator, exact witness replay/slew and float/bool refusal.
No roundoff margin in the rational computation. This certifies mathematical supplied
numbers, not physically calibrated parameters. Restricts constant B, independent
componentwise actuator/slew, fixed previous control and positive dt. No corridor,
scenario intersection, time-varying B, coupled constraints, hardware or safety claim.
Fraction growth/resource limits unprofiled. Returns Fraction objects for in-process
use, not JSON-ready. Earlier floating modules untouched. Review pending.

Reachable cumulative integral per actuator is an interval since the feasible control
polytope is convex; terminal set is B times their Cartesian product plus initial
state under these independent constraints. This observation motivates future reduced
terminal solvers but no such joint solver is implemented in this unit.
