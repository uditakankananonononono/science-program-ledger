MSplots.ipynb: Jupyter notebook containing the Python scripts underlying all manuscript and supplementary figures. Requirements: matplotlib, numpy, PIL, python3, h5py
Fig[X]: data files underlying the respective plots. See individual README files for details.
compressed_videos: X264 compressed versions of the unprocessed videomicrographs underlying the figures and supporting videos.
Note that all numerical data stored in hdf5 files has been cropped to 100000 time steps and then decimated by 4, as the full data set totals 5GB of uncompressed text files. The authors are happy to share the full data on reasonable request.
