# Explicit joint-arrival payload baseline

Established discrete expectation/probability algebra, not a physical correlation model
or invention. Caller supplies complete nonnegative rational masses summing exactly to
one over 0/1 target-arrival outcome rows. Duplicate rows aggregate. Missing outcomes
implicitly zero mass, not measured impossible events. Positive payloads and threshold
explicit; exact marginals/expectation/distribution and threshold/any-arrival outputs.
No off-target joint states, interactions, physics, energy/info/cost or time model.

8 dev methods pass (4 prior + 4 joint). Constructed two-agent cases with identical
p=1/2 marginals and equal total payload have full-payload success 1/2 for common
arrival/failure, 0 for exclusive arrival, 1/4 for independent arrival. Expected target
payload remains 1/2 in each. This is sensitivity to dependence assumption, not a swarm
win/crossover finding. Duplicate rows, heterogeneous weights and invalid probabilities/
non-integer Boolean outcomes tested. Fractions not JSON-ready; caller's joint table
can be exponential, no resource guard. Correlations are supplied, not estimated.
No calibration/physiology/anatomy/scientific gate; earlier baseline untouched. Review pending.
