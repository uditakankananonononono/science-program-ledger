# Bounded independent ternary convolution

Established exact discrete convolution, not invention. Each agent independently has
target/offtarget/lost outcome with supplied rational probabilities. Convolve target
and off-target payload sums, conserving mass and replaying expected payloads. Combined
target/collateral metric is exact under that assumption, not biological safety.

16 dev methods pass (12 prior + 4): explicit independent joint-table enumeration
matches metrics, max-state budget aborts rather than truncates, zero branches skipped,
invalid budgets/probabilities rejected. Default state budget 10000 keys per current/
next distribution; both dictionaries coexist, so this is not a total memory/CPU cap.
Fraction bit growth, input length and arithmetic work unbounded; no scalable solver
claim. RuntimeError returns no partial probability if budget exceeded. Earlier
unbounded baseline modules remain unchanged, not retroactively guarded.

Caller probabilities uncalibrated, independence unvalidated; no physical correlations,
coordination, flow/crowding, energy/info/cost/time equality or swarm crossover claim.
Fractions and tuple keys not JSON-ready. Constructed checks only, no score/holdout/
scientific gate. Independent review pending.
