# P08-05 independent payload-budget sanity baseline

Established exact Bernoulli convolution, not swarm coordination/physics or invention.
Inputs explicitly declare target-arrival probability p, mutually exclusive off-target
arrival q, and positive payload weight per agent. p+q<=1 permits nondelivery. Target
arrivals independent across agents; off-target expectation is linear. No target/off-
target joint distribution, correlations, crowding, controllability, time, flow or
interaction model. No measured arrival probabilities admitted.

Exact rational delivered-target payload distribution conserves probability, outputs
expected target/off-target payload, threshold success and at-least-one target arrival.
Fractions not JSON-ready, worst-case heterogeneous subset-sum state growth exponential.
No population-size/resource guard; small analytic examples only. Floats/bools refused.

Four development methods pass. Equal total payload split among two p=1/2 agents
has any-arrival probability 3/4 but full-payload success 1/4; one p=1/2 agent has
full-payload success 1/2. Expectations target/off-target unchanged under that example.
At threshold half the total, split agents instead have threshold success 3/4.
This demonstrates metric dependence, not a physically valid crossover or swarm win.
Heterogeneous rational weights/probabilities and invalid inputs checked separately.

Only total payload is equalized in the constructed example. Information/energy/cost
budgets not modeled or verified, no equal-budget scientific gate passed. No simulation,
held-out/scored comparison, microscopic calibration, anatomy or physiology claim.
Independent review pending; P08 tracking/field planning modules untouched.
