## What was built
`tool/abbench.py` - locked benchmark harness. See the tool docstring for the full locked protocol:
deterministic test-set rule (SAbDab, 772 candidate non-redundant protein-antigen complexes, target
N = 24), ImmuneBuilder ABodyBuilder2 unrefined Fv modeling, LightDock rigid-body docking (40 swarms /
100 glowworms / 100 steps, modeled arm + crystal-Fv control arm), DockQ scoring, RaSP affinity ranking
on the SKEMPI 2.0 antibody subset (1189 mutations, 56 complexes, data/skempi_ab.csv).

## Locked gates (from the tool docstring, committed before any test-set result)
- G1: median DockQ >= 0.23 on the modeled arm over completed complexes (bootstrap CI); NOT EVALUABLE
  if N < 12 (compute blocker), never silently failed.
- G2: Spearman rho >= 0.4 predicted vs experimental ddG on SKEMPI antibody mutations; documented as
  blocked if RaSP cannot run here, not forced.
- G3: per-stage metrics (modeling RMSD, control-arm vs modeled-arm DockQ, affinity rho) all published.

## Locked amendments vs spec
- N target 24 (from >= 200): 2-core/2 GB VM budget.
- ImmuneBuilder (unrefined) replaces MODELLER+MD; LightDock replaces HADDOCK; no ProABC-2 stage
  (no public implementation runnable here) - the paratope-F1 stage is dropped, documented.
- SKEMPI antibody subset defined as SKEMPI 2.0 rows whose PDB appears in SAbDab (parsed affinities).
