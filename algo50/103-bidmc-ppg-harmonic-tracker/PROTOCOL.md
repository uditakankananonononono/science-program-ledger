# P103 preregistration (locked before any HR estimate was scored)
Task: heart rate from the BIDMC PPG (PLETH, 125 Hz), reference = Numerics "HR" column (1 Hz, monitor ECG-derived), 8-s windows, 2-s hop; reference = mean HR over the window (NaN skipped; windows with no reference dropped).
DATA SCOPE: BIDMC PPG and Respiration Dataset v1.0.0 (PhysioNet, ODC-BY 1.0), CSV corpus: 53 records x Signals/Numerics (Breaths not used) from the scout-verified complete CSV set: every file SHA256 checked against the official manifest (manifest sha256 e28756681318a18d9c682a68cdff65efcaccb3ece40cfccd380540b77a3fdd6d; per-file hashes in files.tsv, re-verified by my own download script; run.py refuses to run on any mismatch). Not WFDB/Matlab files. No outcome computed before lock. (Note: the first scout report said PARTIAL, records 01-03; the later complete verdict was relayed by main; I rely on my own hash checks.) ICU patients; HR reference is a monitor value, not a hand-annotated gold standard.
SPLIT: DEV (tuning only) = records 01-18; TEST = records 19-53, evaluated once.
Baselines (my re-implementations of published methods; equivalence check = synthetic 72-bpm pulse train, each must land within 2 bpm, else amendment before results): 
 B1 Elgendi et al. 2013 two-event-span peak detector (bandpass 0.5-8 Hz Butterworth order 2, squared, MA_peak 111 ms, MA_beat 667 ms, beta=0.02, min width 111 ms), window HR = 60/median inter-beat interval; <2 peaks -> carry previous estimate (first window: DEV median reference HR).
 B2 FFT-peak: bandpass 0.7-3.5 Hz, Hann, zero-padded FFT power evaluated on a 40-200 bpm grid at 1 bpm, estimate = argmax.
 Headline baseline = lower DEV MAE of B1, B2.
New method HTV (harmonic-score causal tracker): per window, P = power of the Hann-windowed, zero-padded FFT of the 0.7-8 Hz bandpassed window. Score S(f)=sum_{m=1..3} (1/m)*log(P(m*f)+1e-8*max(P)) on a 40-200 bpm grid (1 bpm), P read at m*f bpm; S is z-scored per window. Tracking: causal max-plus filtering across windows within a record, delta_t(f)=S_t(f)+max_f'[delta_{t-1}(f')-lam*|f-f'|], renormalised by subtracting its max each step; estimate_t = argmax_f delta_t (forward only, no backward smoothing, so causal like the baselines). lam tuned on DEV in {0.02,0.05,0.1,0.2,0.5} (grid edges 0.02 and 0.5 declared; edge selection will be reported); ties -> larger lam.
Metric: MAE (bpm) per record, averaged over windows; paired per-record diff (baseline minus HTV) over the 35 TEST records; 95% CI by record bootstrap (10000, seed 7). WIN: relative MAE reduction >= 10% AND CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. No re-banding. Secondary descriptive: window-level MAE, median AE, fraction of windows with error > 5 bpm, per-record win count. 
Disclosures: re-implemented baselines; monitor HR reference has its own artefact; ICU population small (53); records are 8 minutes.
