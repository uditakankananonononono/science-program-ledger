# P7 preregistration (locked before any external-site evaluation)
Data: UCI Heart Disease (ID 45, CC BY 4.0), zip sha256 b17cd273da9ce1caa4710fce80227ea454d4dbf9fcbc8e6a9121672751563adc; files processed.cleveland/hungarian/switzerland/va.data (14 columns age,sex,cp,trestbps,chol,fbs,restecg,thalach,exang,oldpeak,slope,ca,thal,num). '?' = missing; additionally chol==0 and trestbps==0 are treated as missing (0 is a missing-value code at Switzerland/VA). Target = num>0.
Split: TRAIN = Cleveland (all 303). External test sites (fresh, touched once): Hungarian (294), Switzerland (123), VA (200); pooled and per-site.
Baselines (chosen on Cleveland 5-fold stratified CV AUROC, StratifiedKFold shuffle seed 0): B1 median imputation (train medians) + RandomForest(300, random_state 0); B2 IterativeImputer (MICE-style, max_iter 10, random_state 0, sample_posterior False) + logistic regression (standardised, C=1). Headline = higher Cleveland CV AUROC.
New method RFB (reduced-feature bank, imputation-free): for each test row with observed feature set O (|O|>=3), predict with a model trained on the Cleveland rows restricted to features O: average of logistic regression (standardised, C=1) and RandomForest(200, max_depth 4, random_state 0) probabilities; Cleveland rows with missing values in O are dropped for that model (fallback when fewer than 60 rows remain or |O|<3: training prevalence). Models cached per pattern. No tuning.
Metric (primary): pooled AUROC over the 617 external patients (rank-based); paired bootstrap over patients (10000, seed 7) of AUROC(RFB) - AUROC(headline baseline). WIN: diff >= +0.02 and CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. Per-site AUROCs reported; Switzerland has very few negatives so its AUROC is unstable and reported for completeness only.
Equivalence check: with no missing values in a test row RFB's pattern equals the full feature set and must equal the full-feature average model (asserted on Cleveland-train rows).
Disclosure: sites differ in prevalence and measurement; one training site; no separate hyperparameter tuning; bootstrap over patients not sites.
