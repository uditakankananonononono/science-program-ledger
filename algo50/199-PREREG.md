## Scope
No script in the repo regenerates ensemble_oof.csv, so nothing here reproduces the claim's pipeline. This audit (a) recomputes the AUROC arithmetic of the committed OOF file and (b) re-stacks the COMMITTED base-layer scores. Base layers are not retrained. Same-organisation. Whether it counts toward any tally is the parent's decision; the claim is not on the ledger board (it is in memory only).
Base-layer classification from repo code: fba_min, fba_rich = label-free (computed from the iJO1366 model, no labels). gnn, cnn, kmer = supervised, trained with the Gerdes labels and evaluated out-of-fold with their own 3-fold splits (run_gnn.py / run_seqcnn.py), folds not aligned to the stacker's.
## Parts and criteria
A1 arithmetic: exact bnumber join of aligned file, ensemble_oof.csv and data/gerdes_labels.csv; report join sizes, labels missing in gerdes_labels.csv, mismatches (listed). PASS iff recomputed AUROC of ensemble_oof.csv within 0.0005 of 0.7225 AND label agreement (aligned vs gerdes_labels, genes missing there counted as disagreements) >= 99%. If mismatch < 1% the aligned/oof file labels (the claim's own) are retained for all other parts. A1 fail = "claim-artifact mismatch".
A2 re-stack (StandardScaler + LogisticRegression C=0.5, balanced, max_iter 4000 on the 5 base columns; StratifiedKFold 3, shuffle, seed 7; hyperparameters taken from the repo's own run_ensemble_v2.py re-stack because v1's are not committed): PASS iff AUROC in [0.7125, 0.7325] (+-0.01). The point value vs 0.7225 is reported regardless. Tolerance justification: seed-to-seed stack variability is measured in B; +-0.01 is the tightest window I can set without seeing the repo's own v2 re-stack value (deliberately not opened).
B seed robustness: the same stack with 20 CV seeds 1001..1020, each compared with the strongest single base column by full-sample AUROC (single columns have no CV dependence; identity fixed by point AUROC). PASS iff the stack AUROC exceeds the strongest single column's AUROC in all 20 seeds. Mean and min reported.
C paired bootstrap: B=2000 resamples of genes (unit = gene, with replacement, skip degenerate resamples), 95% percentile CI, seed 7, AUROC(A2 stack) minus AUROC(strongest single column). PASS iff CI lower > 0.
D permutation: 200 label permutations (seed 1) applied before the stack's CV, base scores fixed, CV seed 7. PASS iff 95th percentile of permuted AUROC < 0.55 AND real A2 AUROC > the permutation maximum. D2 hard control: each base column shuffled independently across genes (50 reps, seed 2). PASS iff mean AUROC in [0.47, 0.53]. Neither detects second-order stacking leakage.
F (report only, no pass/fail): stack of the two label-free layers (fba_min, fba_rich) with the same CV (seed 7 and 20 seeds) and paired bootstrap vs the better label-free single column. This is the only leakage-free comparison available here.
