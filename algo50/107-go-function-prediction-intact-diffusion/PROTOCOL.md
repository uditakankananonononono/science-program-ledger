# P107 preregistration (locked before any function-prediction score was computed)
Task: predict NEW Gene Ontology annotations of human proteins from the IntAct physical-interaction network, with a temporal holdout.
DATA SCOPE: (a) IntAct human physical compact projection (scout-verified source, CC BY 4.0; file sha256 7e9f6bba8ea0511e510b71a383817dc22b32469e799bb3457c769e331d442a85; curation-date edges as in P97; IntAct not BioGRID); (b) GO release 2026-07-26 archive members HUMAN-uniprot.gaf.gz (sha256 a0afba19dfb1f8fa996bc1bdcd61fd0c9bd4cf0d2bf2509d09ac86993c0e70a2) and go-basic.obo (sha256 b08d45b268b8c24ccb2513dbbbc7d4df9f6521c099b413f79eb31e06e0fa3bcc), CC BY 4.0, from the same GO archive; all hashes re-verified by run.py. Both data sets were used in P97/P105 (different tasks: link prediction; enrichment simulation); no function-prediction outcome has been computed on them.
Time design: ANNOTATION CUTOFF 2022-01-01 using GAF column 14 (annotation date). TRAIN labels = annotations dated <= 2021-12-31, propagated to ancestors (is_a, part_of; as in P105), any evidence except ND/NOT. TEST positives = (protein, term) pairs whose annotation is dated >= 2022-01-01, evidence code in the experimental set {EXP,IDA,IPI,IMP,IGI,IEP,HTP,HDA,HMP,HGI,HEP}, propagated, that are NOT already in the propagated train labels. Network = IntAct edges first curated <= 2021-12-31 (the same cutoff). Caveat: GAF annotation dates are the dates of the latest regeneration for many UniProt IEA rows (483k rows carry 2026), which is why experimental evidence is required for TEST positives and why train labels (<=2021) may be a biased sample; disclosed. Proteins considered: those in the network with >=1 train annotation and >=1 neighbour.
Terms: propagated GO terms with 10 <= train-annotated proteins <= 300 within the considered proteins AND >=5 TEST positives. Terms sorted by id; even positions = DEV, odd = TEST. For a term, eligible proteins = considered proteins NOT annotated to the term in train; positives = eligible with a TEST positive; negatives = the other eligible proteins.
Methods (scores for every considered protein x term, then AUROC per term on eligible proteins):
 B1 neighbour frequency (guilt by association): row-normalised adjacency times train label matrix.
 B2 two-hop random walk: (row-normalised A)^2 times train labels (self-return removed by zeroing the diagonal of the 2-step operator).
 Headline baseline = higher DEV macro-AUROC of B1, B2. (Published family: Schwikowski 2000 neighbour counting; Sharan 2007 review.)
 New DCD-F (degree-corrected diffusion): An = D^-a A D^-a; S = (An Y) + w2 (An^2 Y with zeroed diagonal); final score = S / (deg+1)^b (b>=0 deflates hub bias). a in {0.5,0.75,1}, w2 in {0,0.5,1}, b in {0,0.5,1}; 27 configs chosen by DEV macro-AUROC (ties -> smaller a, then smaller w2, then smaller b). Grid edges declared (a 0.5/1, w2 0/1, b 0/1); edge selection reported.
Metric: macro-AUROC across TEST terms (terms where an AUROC is defined). Paired per-term difference (DCD-F minus headline); 95% CI by bootstrap over TEST terms (10000, seed 7). WIN: macro diff >= +0.02 and CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. Also report: number of TEST terms, median positives per term, fraction of terms where DCD-F beats the headline. No re-banding.
Equivalence check (asserted before scoring): on a hand-built 5-node path graph with one labelled node, B1 gives [0,0.5,0,0,0], B2 gives [0,0,0.25,0,0] (hand computed), and DCD-F with a=1,w2=0,b=0 equals D^-1 A D^-1 Y on the same graph. (Hand values corrected before any scoring; my first draft's expected values were wrong.)
Exposure: protein-id coverage/overlap counts and date histograms only before lock.
