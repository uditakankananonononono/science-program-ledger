# P4 preregistration (locked before any clustering or ARI computation)
Data: PBMC3k raw h5ad via Scanpy-referenced mirror https://falexwolf.de/data/pbmc3k_raw.h5ad, sha256 89a96f1beaa2dd83a687666d3f19a4513ac27a2a2d12581fcd77afed7ea653a1 (original 10x PBMC 3k, CC BY 4.0 explicit on Cell Ranger 1.0.0 page, not confirmed for 1.1.0; swappable dataset, no publication claim).
Preprocessing (both arms identical): filter cells min_genes=200, genes min_cells=3, remove cells with pct_mito>5 or n_genes>2500 (mito prefix MT-), normalize_total 1e4, log1p, HVG (top 2000, seurat flavor) EXCLUDING the marker panel below, scale max 10, PCA 30 comps (arpack, random_state 0).
Frozen labels (rule, computed from normalized log expression BEFORE any clustering): panel = CD3D,CD3E,IL7R,CCR7,CD8A,CD8B,NKG7,GNLY,MS4A1,CD79A,CD14,LYZ,FCGR3A,MS4A7,FCER1A,CST3,PPBP. Class score = mean z-score of markers: T={CD3D,CD3E,IL7R}, NK={NKG7,GNLY} (and CD3D z<0.5), B={MS4A1,CD79A}, CD14mono={CD14,LYZ}, FCGR3Amono={FCGR3A,MS4A7}, DC={FCER1A,CST3}, Mega={PPBP}. Label = argmax class score if top score >= 1.0 and margin to second >= 0.5; otherwise unlabeled (excluded from ARI). Marker panel is excluded from clustering features to limit circularity; residual circularity (marker-correlated genes) disclosed.
Baseline B: sc.pp.neighbors(n_neighbors=15, n_pcs=30) + sc.tl.leiden(flavor='leidenalg', resolution=0.8, random_state=seed).
New method DALR (dropout-aware edge reweighting): take the kNN graph (n_neighbors=15), each edge weight w_ij = c_ij * (1 - |q_i - q_j|)^2 where c_ij is the Scanpy connectivity and q = rank-normalised (0..1) fraction of zero HVG entries per cell (a dropout propensity). Then Leiden (same params).
Seeds 0..19 (Leiden random_state). Primary metric: ARI vs frozen labels on labeled cells, mean over seeds; paired difference DALR-B, 95% bootstrap CI over seeds (10000, seed 7). Secondary: NMI, n clusters. Resolutions 0.4 and 1.2 reported as sensitivity only.
WIN: diff >= +0.02 and CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. Verbatim, no re-banding. Disclosure: variation is Leiden-seed only; there is one dataset, so it is not a replication across cell populations.
Equivalence check: exponent 0 (weights = c_ij) must give clusterings identical to B per seed (asserted).
