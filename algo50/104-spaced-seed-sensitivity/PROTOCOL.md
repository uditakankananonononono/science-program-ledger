# P104 preregistration (locked before any sensitivity computation)
Surface: seed design for read mapping. Question: can a spaced-seed pattern optimised on dev genomes under an indel-aware error model beat the published PatternHunter seed (Ma, Tromp, Li 2002: 111010010100110111, weight 11) and the contiguous weight-11 seed on a held-out genome?
Data (hash-verified in P3's PREREG): DEV genomes phiX174 NC_001422.1 and lambda NC_001416.1; HOLDOUT E. coli K-12 NC_000913.3 (reference genome used only for simulation; no sequencing-read dataset). NCBI policy caveat as in P3.
Read model (all genomes): forward strand, length 80 from uniform start; per reference base: substitution 10%, insertion 2%, deletion 2% (sequential Markov, RandomState seeds below). Hit definition: a seed at read offset o hits iff every weight position of the pattern is a MATCHED base on the SAME alignment diagonal (true location). Read is sensitive if any offset hits. (Known simplification: forward strand, uniform error, no real quality model.)
Candidate search (DEV only): 600 random patterns, length uniform 14..26, weight exactly 11, first and last position set, RandomState(0); score = sensitivity on 1,500 DEV reads (seed 1; reads drawn half from phiX half from lambda). Declared edge: length 14-26. The best-scoring candidate is NEW (ties: shorter). PatternHunter and contiguous-11 are scored on the same DEV reads for reference but are not selection candidates.
Test (HOLDOUT): 3,000 E. coli reads (seed 5), same read model. Metric: sensitivity; paired bootstrap over reads (10000, seed 7) of sens(NEW) - sens(PatternHunter). WIN: diff >= +0.01 and CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. Secondary: vs contiguous; mean number of off-target exact seed matches per read in the E. coli index (specificity check, first 300 reads), reported verbatim.
Equivalence check: contiguous-11 sensitivity computed by this diagonal logic must equal sensitivity computed by a direct string-matching scan on the first 200 holdout reads (asserted).
Disclosure: simulated reads, one error model, one held-out genome; weight fixed at 11 so the comparison is at equal nominal weight, but specificity is reported not equalised.
