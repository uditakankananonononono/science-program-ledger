# P99 preregistration (locked before any forecast was scored)
SCOPE (PARTIAL, per the scout): CMU Delphi epidata mirror of CDC FluView national ILINet, NOT a direct CDC extract; CDC terms unverified; mirror claims US-government public-domain provenance. File: https://api.delphi.cmu.edu/epidata/fluview/?regions=nat&epiweeks=199740-202639 , 1,418 weeks 199740-202638 (end week 202639 requested but absent), 400,911 bytes, sha256 3101cac5e7dae360f18489d9ddf39969d6e672de769a9c3365079f139f07e806 (re-verified locally). Values are the LATEST ISSUE per week (finalised), not real-time vintages: backfill effects are NOT modelled; disclosed as a limit. Series = wili, log-transformed.
Weeks: epiweek 40 to 20 (flu season) only; early seasons (1997-2001) have no summer weeks. Season s = epiweeks 40 of year s to 20 of year s+1. Forecast origin t (any in-season week), horizons h=1..4 weeks, targets must be in the same season.
Libraries/splits: LIBRARY = seasons 1997/98..2014/15 (all; 2009/10 pandemic kept). VAL (tuning only) = seasons 2010/11..2014/15 using library 1997/98..2009/10. TEST = seasons 2015/16..2018/19 and 2019/20 up to epiweek 202010 (pre-COVID cut), using the full LIBRARY; TEST touched once. Secondary (reported, no verdict): 2022/23..2025/26 with the same library.
Baselines: B0 persistence (forecast = last value). B1 direct AR(3): for each h, OLS regression of y_{t+h} on y_t,y_{t-1},y_{t-2} and week-of-season dummies, fitted on the library (not ARIMA; a direct multi-step autoregressive baseline, stated plainly). Headline baseline = the lower VAL MAE of B0, B1.
New method ARA (analog regime forecaster): features at origin t = last W log values (W in {3,4,6}); distance to every library window with the same lag structure = Euclidean on the W values + lam*|week-of-season difference| (lam fixed 0.05); take the k nearest (k in {3,5,10}) library windows; forecast y_t + weighted mean (weights 1/(d+1e-3)) of their future DELTAS (y_{t'+h} - y_{t'}). W and k chosen by min VAL MAE pooled over h; ties smaller W then smaller k; grid edges declared.
Metric: MAE of log wILI forecasts pooled over origins and horizons 1-4. Paired difference |err_base|-|err_ARA|; primary CI = moving-block bootstrap over TEST origins in time order (block 4, 10000 resamples, seed 7); also report a season-level bootstrap (5 seasons, descriptive). WIN: relative MAE reduction >= 5% and CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. Also per-horizon MAE. No re-banding.
Equivalence check: with k=1 and the library window set to the same season's own previous year... (omitted) ; instead check that ARA with lam large and a library of one identical window reproduces persistence plus that window's delta (unit assert on synthetic data).
Disclosure: finalised-issue data (optimistic: forecasters get cleaner inputs than real time), small number of test seasons, mirror not CDC.
