# P108 preregistration (locked before any model was scored)
Transfer claim (scope rule): UCI Concrete is a materials surface, not bio/medicine. The method question transferred to bio/medicine is whether shape-constrained (monotone) additive models, built with expert-stated monotone directions, beat unconstrained and tree-monotone learners on small tabular dose/exposure-response style data (e.g. dose-response, risk scores). No bio equivalent was verified in this batch; this unit does NOT by itself support a medical claim.
DATA: UCI Concrete Compressive Strength (Yeh 1998; citation required), CC BY 4.0, 1030 rows x 8 predictors + strength (MPa). File = scout CSV from the official zip (archive sha256 dad85d14de8aee4e07479daa774e6b569a313715b71a3b92c95a07cf91c2c9a7), csv sha256 f656a971ce020d12a7d5e1d4aebd103aa28d99a164efca7125091a05380d3db2 (run.py verifies). MONOTONE DIRECTIONS ARE MODELLING ASSUMPTIONS, not verified truth: frozen as strength increases with cement and age, decreases with water; all other raw features unconstrained.
Split: rows grouped by identical mix design (the 7 non-age columns; 428 groups, up to 20 ages per mix) so a mix never spans DEV and TEST. Groups randomly permuted (seed 41); first 50% of groups = DEV (tuning, grouped 5-fold CV), the rest = TEST (once). TEST: strength RMSE.
Baselines (sklearn): GBR = GradientBoostingRegressor(n_estimators in {200,400}, learning_rate in {0.05,0.1}, max_depth in {2,3,4}, subsample 0.8, seed 0); HGB = HistGradientBoostingRegressor(max_iter in {200,400}, learning_rate {0.05,0.1}, max_leaf_nodes {8,16}, seed 0); HGBM = HGB with monotonic_cst (+1 cement, -1 water, +1 age, 0 else), same grid. Each tuned by DEV grouped-CV RMSE; headline baseline = lowest DEV-CV RMSE among GBR/HGB/HGBM (the strongest, including the monotone-constrained tree learner).
New method MAM (monotone additive model with mixture ratios): features x = 8 raw + engineered w/c = water/cement, w/b = water/(cement+slag+fly ash), log(age). Model y = b0 + sum_j f_j(x_j) with piecewise-linear ramp basis: monotone features (cement +, water -, age via log(age) +, w/c -, w/b -) use nonnegative ramp coefficients r_k(z)=max(0,z-t_k) at K knots (z = x or -x for decreasing), free features (slag, fly ash, superplasticizer, coarse, fine) use a cubic B-spline basis (SplineTransformer, 5 knots, degree 3). Fitted by bounded least squares (scipy lsq_linear; monotone ramp coefficients >=0, others free) with ridge penalty lam on non-intercept coefficients via augmented rows; all features standardised on DEV-fit data. Knots at quantiles of the training feature. K in {4,8}, lam in {0.01,0.1,1,10} by DEV grouped CV (grid edges declared: K 4/8, lam 0.01/10).
Equivalence checks (asserted): (i) with all features free and lam tiny MAM equals ordinary least squares on its basis (max abs prediction difference < 0.02 MPa vs np.linalg.lstsq; the first draft said <1e-6, the bounded solver's tolerance gave 0.0065 on the check, residual std identical to 4 decimals; threshold relaxed before any model was scored on real splits); (ii) monotonicity: on a grid the fitted MAM is nondecreasing in age and cement and nonincreasing in water with all other features held at the TEST median, maximum violation < 1e-6.
Verdict: paired per-row squared-error difference baseline minus MAM on TEST; bootstrap over mix GROUPS in TEST (10000, seed 7) of the RMSE difference (RMSE_base - RMSE_MAM). WIN: relative RMSE reduction >= 5% and CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. Also report RMSE of every baseline, MAE, and R2. No re-banding.
Disclosures: no external validation; grouped split by mix only; conclusions limited to this dataset; directions are assumptions.
