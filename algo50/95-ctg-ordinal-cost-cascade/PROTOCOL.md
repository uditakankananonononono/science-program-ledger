# P9 preregistration (locked before any test-split evaluation)
Data: UCI Cardiotocography (ID 193, CC BY 4.0), zip sha256 ba2853564e282779907242b7bd8a83265d9fc4e79bb008573967daa16677bb6c; sheet 'Raw Data', 2,126 labelled segments from 352 recordings (FileName), target NSP (1 Normal, 2 Suspect, 3 Pathologic).
Features (21, no label-derived columns): LB,AC,FM,UC,ASTV,MSTV,ALTV,MLTV,DL,DS,DP,Width,Min,Max,Nmax,Nzeros,Mode,Mean,Median,Variance,Tendency. Excluded: CLASS, SUSP, A,B,C,D,E,AD,DE,LD,FS (pattern-class columns that encode the label), FileName/Date/SegFile/b/e/LBE.
Split (frozen by rule): sorted unique FileName, RandomState(0).permutation, first 30% of recordings = TEST, rest = TRAIN; segments follow their recording (no recording straddles).
Decision cost matrix C[true][pred], order (Normal,Suspect,Pathologic): [[0,1,2],[3,0,1],[10,4,0]]. Primary metric = mean cost per TEST segment (lower better).
Arms (hyperparameters by 5-fold GROUP CV on TRAIN, recordings grouped, GroupKFold seeded by the sorted order): B1 RandomForest(500, random_state 0) argmax; B2 RF probabilities + Bayes-risk decision argmin_pred sum_true p(true)*C[true][pred]; B3 multinomial logistic regression (C in {0.1,1,10}, standardised) + Bayes-risk decision. Headline baseline = best mean group-CV cost among B1-B3.
New method OCC (ordinal cost cascade): stage 1 HistGradientBoosting P(NSP>=2); stage 2 HistGradientBoosting P(NSP=3 | NSP>=2) trained on NSP>=2 only (both random_state 0, max_depth in {3,None}, learning_rate 0.1, max_iter 200, depth chosen by group-CV); decisions: predict Pathologic if p1*p2 >= t2, else Suspect if p1 >= t1, else Normal; thresholds t1,t2 each in {0.05,0.1,...,0.95} (edges 0.05 and 0.95 declared) chosen on out-of-fold TRAIN predictions by min mean cost.
Statistic: paired bootstrap over TEST recordings (10000, seed 7) of mean-cost(OCC) - mean-cost(headline baseline). WIN: difference <= -0.03 (OCC cheaper) with 95% CI upper < 0. NEGATIVE: CI lower > 0. Else NULL. Verbatim, no re-banding. Secondary: macro-F1, per-class recall, accuracy.
Equivalence check: the cost function applied to the identity prediction (truth) must be 0 and to the all-Normal prediction must equal the matrix-weighted class prior (asserted).
Disclosure: one dataset; no external fresh site. TEST touched once.
