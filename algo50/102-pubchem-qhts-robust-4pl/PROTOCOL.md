# P102 preregistration (locked before any curve was fit)
DATA SCOPE (PARTIAL, per scout): PubChem AID 720691 and AID 720692 (Tox21 glucocorticoid receptor qHTS; NCATS/NCGC), FIRST 100 SIDs in publisher order each, NOT the full assays (10,486 SIDs each). Files re-downloaded by me from the scout's exact PUG-REST URLs (source_url in b3/ev/AID*-first100.integrity.json) and re-hashed: AID720691 1,264,868 B sha256 0a8f6226da0c193038f07a9efad07c6c949c47d23f21756c2e03a509527f5cec; AID720692 1,266,634 B sha256 ee72d53f56d7a504891024d2d5da395d88dedfc4f3ce6f36b42a99ad26cdd14b. Blanket public-domain status of PubChem contributed data NOT verified (NCBI policy warns of protected contributed material). The first rows of each file are 5 schema rows (no SID), dropped.
Units: three replicate curves per sample (Replicate_1..3), up to 25 concentrations (uM) each; response = "Ratio-Activity at <conc> uM" columns. Curve = replicate with >=8 non-missing points. Responsive curve = max |response| >= 20. Compound = a SID row with >=2 responsive curves. AID720691 has only 4 such compounds (and 0 Active outcomes in 100 SIDs): NOT analysed (reported as excluded). AID720692 (44 compounds at lock time) is the analysis set; it is small, so the test is underpowered by design (22 TEST compounds); disclosed.
Task: estimate AC50 per curve; replicate concordance = for each compound, mean absolute pairwise difference of log10 AC50 among its responsive curves (lower = better).
4PL: y = bottom + (top-bottom)/(1+10^((logAC50 - x)h)), x=log10(conc uM). logAC50 estimates clipped to [min x - 1, max x + 1] for BOTH methods; a failed fit is assigned max x + 1 for both (declared).
Baseline B: scipy.optimize.curve_fit (lm, no bounds), p0=[min y, max y, median x, 1], max 2000 evaluations (the standard nls-style fit).
New R (robust multistart): scipy least_squares, loss soft_l1 with f_scale tuned on DEV in {5,10,20} (edges 5 and 20 declared), bounds bottom in [-150,150], top in [-250,250], hill in [0.3,4], logAC50 in [min x -1, max x +1], 5 starts (logAC50 at the 10,30,50,70,90th percentiles of x; bottom/top from y min/max, hill 1), keep lowest-cost fit.
Split: the 44 compounds sorted by SID: even positions = DEV (f_scale tuning only), odd positions = TEST (once).
Guard against a degenerate 'agree-by-shrinking' fit: on curves that carry a PUBLISHER fit (Ratio-Fit_LogAC50, log10 M; compare x-6), median |logAC50_method - publisher| of R must be <= that of B + 0.1 (log10) over TEST curves; if fewer than 8 publisher-fit TEST curves exist, the guard is reported as UNEVALUABLE and the verdict cannot be WIN.
Verdict (per-compound paired diff B minus R on TEST; bootstrap over compounds 10000, seed 7): WIN = relative reduction of the mean >= 10%, CI lower > 0, guard satisfied. NEGATIVE = CI upper < 0. Else NULL. No re-banding. f_scale chosen by minimum DEV mean concordance (ties -> larger).
Equivalence check: both fitters must recover logAC50 within 0.05 of truth on 20 noise-free synthetic 4PL curves (hill 1-2, logAC50 in range).
