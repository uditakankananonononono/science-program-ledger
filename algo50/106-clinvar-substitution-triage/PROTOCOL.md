# P106 preregistration (locked before any model was trained or scored)
DATA SCOPE (PARTIAL, per scout): ClinVar balanced extract, NOT whole ClinVar and NOT representative clinical ground truth: 600 distinct missense variants, 300 positive (Pathogenic/Likely pathogenic) vs 300 benign-class (Benign/Likely benign), all >=1-star, first-300-eligible per class in ESearch return order (convenience sampling; submitter batches and genes may concentrate; 593 of 600 are 1-star single-submitter). File clinvar-missense-balanced-600-d04967be.tsv, sha256 c04713fd7a23d8816034a3e550753d0682298e307fce7ea0460f00615b1d1f24 (run.py verifies). Date = classification last evaluated. VUS, conflicting, zero-star and multi-gene excluded. Rights: NCBI no-restriction policy, no grant of third-party submitter rights; attribution to NCBI ClinVar requested (PMID 29165669); NOT labelled CC0. Research benchmark only, not for diagnostic or medical use.
LEAKAGE FACT: 415 of 422 genes contain a single class, so gene identity predicts the label. Therefore: NO gene-identity features; DEV/TEST split is by GENE (genes randomly permuted, seed 5, first half DEV, second half TEST); all tuning uses gene-grouped CV inside DEV; the model for TEST is trained on DEV genes only. Gene never enters features. Position-in-protein is not used.
Features come only from the substitution (ref aa, alt aa parsed from protein_change p.XxxNNNYyy).
Published baselines (no training): BLOSUM62 score (Biopython substitution_matrices; lower = more damaging, so score = -BLOSUM62) and Grantham 1974 distance (constants c,p,v per amino acid; D=sqrt(1.833 dc^2+0.1018 dp^2+0.000399 dv^2)*50.723). Equivalence check: Grantham must reproduce published values Cys-Trp 215 (+-2), Ser-Arg 110 (+-2), Leu-Ile 5 (+-1); BLOSUM62 Biopython value A-A=4, W-W=11.
Trained baseline LR2: logistic regression on [-BLOSUM62, Grantham/100]. Headline baseline = best DEV gene-grouped-CV AUROC among BLOSUM62, Grantham, LR2 (CV for LR2; unsupervised scores evaluated on all DEV).
New method SUB-LR: logistic regression (L2, C tuned on DEV gene-grouped 5-fold CV in {0.03,0.1,0.3,1,3}; edges 0.03 and 3 declared) on: -BLOSUM62, Grantham/100, change in Kyte-Doolittle hydropathy, change in side-chain volume (Grantham v)/100, one-hot ref aa (20), one-hot alt aa (20), and one-hot of 7 physicochemical classes (AVLIM, FWY, STNQ, KRH, DE, G, PC) for ref and alt, plus whether ref class == alt class.
Metric: AUROC on the TEST genes. Paired difference SUB-LR minus headline baseline AUROC; 95% CI by gene-cluster bootstrap over TEST genes (5000, seed 7). WIN: diff >= +0.03 and CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. Also report AP and class balance in TEST. No re-banding.
Disclosures: the benchmark may reward batch artefacts (submitters tend to assert classes for certain substitution types); 300 test variants; 600 total; no external conservation or population-frequency features were available/used, so this is a substitution-only triage and is far weaker than real predictors.
