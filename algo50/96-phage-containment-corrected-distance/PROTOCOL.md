# P10 preregistration (locked before any sketch/distance computation)
Corpus (scout proposal pack d0df5023, adopted verbatim by this freeze): 60 complete RefSeq NC_ phage genomes, 6 ICTV families x 10 (Ackermannviridae, Straboviridae, Herelleviridae, Drexlerviridae, Demerecviridae, Zobellviridae); manifest.csv lists accession, family, FASTA sha256 (re-verified against the local bytes before running). Taxonomy pinned to ICTV MSL41.v1 (2026-03-20; xlsx sha256 9d262d7864f1f619445a897ae568718ed15b1309c8f0c157a12fd7fb9fd07801). NCBI lineage snapshot has NO dated release (retrieval date 2026-10-07, XML sha256 7feb45be...9063); freeze is against that exact snapshot, not a dated taxdump. NCBI policy: no NCBI restriction; third-party rights not cleared; not CC0.
External tool: Mash v2.3 official marbl Linux64 release, tar sha256 543a9b8b3e60a05a374e7566cc9f4838df186a80b4f16cd69e812841d0ba6582.
Task: family assignment of each genome by leave-one-out 1-nearest-neighbour using a sketch distance (ties: smallest accession in sorted order). Truth = ICTV family.
Arms: BASE = Mash binary `mash sketch -k 13 -s 100 -S <seed>` + `mash dist` (canonical k-mers, seeds 0..19). NEW = CCD (containment-corrected distance): own Python bottom-s sketch of canonical 13-mers (splitmix64 hash xor seed, s=100, same seeds), merged bottom-s of union gives shared count j and Jaccard J=j/s; union size U estimated from the merged sketch's s-th smallest hash h_s as (s-1)/(h_s/2^64); intersection I=J*U; per-genome size n_X=(s-1)/(h_max,X/2^64); C=min(1,I/min(n_A,n_B)); D=-ln(C)/13 (D=1 if I=0).
Primary: mean LOO 1-NN family accuracy over 20 seeds, paired difference CCD-BASE, 95% bootstrap CI over seeds (10000, seed 7). Secondary: Spearman of sketch distance vs EXACT canonical-13-mer-set Jaccard distance (Mash formula on exact J) over all 1,770 pairs; the same at k=21,s=1000 (sensitivity only, all other parts identical).
WIN: diff >= +0.02 and CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. Verbatim, no re-banding. Corpus is one 60-genome set; variance is hash-seed only, disclosed.
Equivalence check: a Python implementation of the plain Mash estimator (same sketches) must reach Spearman >= 0.95 with the Mash binary's distances on pairs with j>0 (seed 0, k=13, s=1000), else the harness is declared defective before any result.

## Amendment A1 (after the equivalence check failed, before any accuracy result existed)
First run (commit 6a0d363): the preregistered equivalence check FAILED: Spearman between the Python Mash estimator and the Mash binary was 0.584 over 1,378 pairs with j>0 (threshold 0.95); the run aborted before any accuracy or CCD result was computed (log: run_v1_equiv_fail.log). Diagnosis hypothesis: most of those pairs have j of 1-5 shared hashes out of 1000, so their distances are Poisson-noise-dominated and rank correlation across different hash functions is low by construction. Amendment: the equivalence check is restricted to pairs where BOTH implementations give distance < 0.5 (substantial J), threshold unchanged (0.95). If it still fails, the harness is declared defective and no accuracy is reported. Nothing else changed.

## Amendment A2 (after A1 also failed; still before any accuracy or CCD result)
A1 run (log run_a1_equiv_fail.log) gave the identical Spearman 0.5837 on the identical 1,378 pairs: A1's restriction removed nothing, because at k=13 every pair with j>=1 has distance < 0.5. Diagnostic (seed 0, k=13, s=1000, no accuracy results): Python-Mash vs exact Spearman 0.712; binary vs exact 0.758; Python vs binary on pairs with both D<0.2: 0.995 (53 pairs), D<0.3: 0.981 (97 pairs), D<0.4: 0.584 (638 pairs). Reading: the two implementations agree on informative pairs and disagree only on the noise-dominated bulk (j of a few hashes). Amendment: the equivalence check uses pairs with BOTH distances < 0.3, threshold 0.95 unchanged. Disclosure: this cutoff was chosen after seeing these diagnostics; they are equivalence diagnostics, not outcome measures.
