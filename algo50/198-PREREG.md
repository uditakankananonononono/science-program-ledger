## Metric (primary, frozen for B and C)
All 38 ligand heavy atoms. Reference = 7KX5 chain A HETATM X7V (38 heavy atoms, no altlocs; the code asserts this), bond orders/stereo assigned from the ideal ligand SDF template. Pose = first MODEL of the pose PDBQT returned by repo dock_ligand (it returns only the single best-energy pose, so no choice among poses is possible; never best-of-nine). Pose topology/stereo come from the PDBQT's own REMARK SMILES, atoms placed through REMARK SMILES IDX. RMSD = sqrt(mean squared atom distance), minimised over all topology- and chirality-preserving atom mappings (RDKit GetSubstructMatches, uniquify off), NO translation/rotation of either ligand, unchanged receptor frame. Pose-validity gate: atom count 38, at least one stereo-preserving mapping exists, parse succeeds; any violation = failure for that run (RMSD treated as infinity), no repair, exclusion or manual mapping. Secondary, reported only: graph-free per-element Hungarian assignment minimising squared distances, no superposition. Pre-lock checks done and disclosed: wrapper self-tests on the reference only (crystal vs ideal template maps with 8 symmetry mappings; crystal self-RMSD 0.0) and a parse/mapping smoke test on the PRE-docking ligand input X7V_ligand.pdbqt (parse OK, a stereo-preserving mapping exists; no RMSD against it inspected). The wrapper's own frozen selftest (meeko-oracle direction proof on the pre-docking ligand PDBQT: pose_mol coordinates vs meeko RDKitMolCreate max deviation 1.2e-7 A; crystal self-RMSD 0.0) passed before lock. ## Parts and criteria
A (Q1): run studies/study12_redock.py unmodified, seeds 42. PASS iff reported RMSD in [0.80, 1.15] A and gate PASS.
B (Q2): same A output pose, primary in-frame metric. PASS iff validity gate passes and RMSD < 2.0 A.
C (Q2): 10 independent redocks, ETKDG seed = Vina seed = 196001..196010, primary metric on the single best-energy pose. PASS iff >= 7 of 10 runs < 2.0 A and median < 2.0 A, where median = numpy median over all 10 values, failures/timeouts/errors counted as infinity. Per-run timeout 3600 s enforced by running each C seed in its own subprocess that is killed on timeout (so a hung native Vina call is covered); a timed-out or errored run is a failure; no seed replacement, no retry, no score-selected reruns, no parameter tuning.
