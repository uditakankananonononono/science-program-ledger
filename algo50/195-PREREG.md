# PREREG unit 195 (locked before any code run or data loaded for this unit)
## Question
Published molecular-property scores are often random-split CV numbers; the official benchmark test is scaffold-split, so they overstate. Does a similarity-reweighted random-CV estimator (uses only unlabeled TEST structures + train_val labels) predict the realized official scaffold-test AUROC of a model panel better than the standard honest proxy (the TDC scaffold validation split)?
## Benchmark
TDC ADMET AMES (Hansen 2009), PyTDC 1.1.15 admet_group('AMES'): train_val 5,821, official scaffold test 1,457 (7,278 total; the TDC leaderboard page lists 7,255 and AUROC metric, https://tdcommons.ai/benchmark/admet_group/21ames/). Leaderboard reference only: top published scores ZairaChem 0.871, ADMETrix 0.870, MapLight+GNN 0.869, MapLight 0.868 (same page). The tool is evaluated on how well it predicts the realized test AUROC, not on reproducing those.
Exposure disclosure: from unit 194 the test positive rate (0.597) is known; no test AUROC of any model in the 195 panel has been computed or seen. TEST labels are used in this unit only at the single final scoring step.
## Model panel (6, fixed, no tuning; Morgan r2 2048-bit binary FP, invalid SMILES dropped and counted)
M1 RandomForest(500, sqrt, leaf 1); M2 ExtraTrees(500, sqrt, leaf 1); M3 LogisticRegression(C=1, L2, max_iter 2000); M4 kNN(k=5, jaccard distance, distance-weighted); M5 LinearSVC(C=0.1) scored by decision_function; M6 HistGradientBoosting(max_iter 200, lr 0.1, max_depth 4). random_state 195.
## Estimators of test AUROC for each model m
E_raw: pooled out-of-fold AUROC of stratified 5-fold random CV on the pool (seed 195).
E_scaf: AUROC on the TDC scaffold validation split (TEST arm: TDC get_train_valid_split default, seed 1; model fit on its train part).
E_sim (candidate): same pooled OOF predictions as E_raw, but weighted AUROC (sklearn sample_weight). s(x) = max Tanimoto (Morgan r2 2048) between x and the training part of its fold (for OOF compounds) or the whole pool (for target compounds). Ten bins with edges at the deciles of s over the TARGET compounds (DEV: pseudo-test compounds; TEST: official test compounds). Weight of OOF compound in bin b = P_target(b) / P_oof(b), clipped to [0.1, 10]; any bin with < 20 OOF compounds merged into the adjacent bin before weighting. No labels of target compounds are used by any estimator.
## Realized value
R_m = AUROC on the target compounds of model m fit on the whole pool (all pool labels), scored once.
## DEV (TEST sealed): scaffold pseudo-target inside train_val
For salt in {1..5}: group train_val by Bemis-Murcko scaffold (acyclic = own group); assign groups to pseudo-target by sha256(scaffold + salt) hash until 20% of compounds, the rest is the DEV pool (80%). Run all three estimators and R_m with pool = DEV pool, target = pseudo-test, E_scaf from a Chemprop-style scaffold split of the pool (largest groups to train, 87.5/12.5, seed = salt). Error per (salt, model) = |E - R|. DEV score = mean abs error over 5 salts x 6 models.
DEV gates: D0 for the panel: mean R_m on pseudo-targets lower than mean E_raw by >= 0.02 AUROC (otherwise there is no leakage gap to correct, DROP). D1: DEV mean abs error of E_sim <= 0.75 x min(DEV mean abs error of E_raw, E_scaf). Otherwise DROP, TEST sealed. Nothing else is tuned; bins, clip and merge rules are fixed above.
## TEST (once, only if D0 and D1 pass)
Pool = train_val (5,821), target = official test (1,457). Errors per model; TEST statistic = mean abs error over the 6 models. WIN iff (1) error(E_sim) <= 0.75 x error(E_scaf) and <= 0.75 x error(E_raw); AND (2) paired scaffold-cluster bootstrap (2000 resamples of test scaffold groups, seed 195; R_m recomputed per resample, estimates fixed) 95% CI of [error(E_scaf) - error(E_sim)] excludes 0. NULL if (2) CI includes 0; LOSS if error(E_sim) > error(E_scaf) with CI excluding 0. Also reported: per-model E_raw, E_scaf, E_sim, R_m (the leakage gap R - E_raw is itself a reported result), AUPRC not needed.
## Disclosures fixed in advance
Importance-weighted validation under covariate shift is established (Sugiyama et al. 2007); similarity-based applicability-domain ideas are established. This is an incremental application test, not a new method class. 6 models share one test set, so the 6 errors are correlated; the bootstrap CI is over test scaffolds, not over models, and conclusions are limited to AMES and this panel. A WIN would show the estimator tracks this one test set, not that it generalises across benchmarks.
