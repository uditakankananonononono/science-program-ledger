Features (label-free, computed once from the raw EDFs, streamed): the 19 channels common to both devices (Fp1 Fp2 F3 F4 C3 C4 P3 P4 O1 O2 F7 F8 T3 T4 T5 T6 Fz Cz Pz; the CONTEK Pg1/Pg2/EOG/EMG and DISCOVERY A2 channels dropped), common-average reference over the 19 channels, 2 s Hann windows hop 1 s at each file's native rate (100, 200 or 256 Hz; 24/759/1148 files used), PSD per window then averaged per file. Band relative power over 1-40 Hz (delta 1-4, theta 4-8, alpha 8-13, beta 13-30, gamma 30-40; the 50 Hz line band is excluded), log. Set BP = 19 channels x 5 bands = 95 features. Set SP = per channel spectral entropy, peak frequency in 6-13 Hz, log total power 1-40 Hz = 57 features. All phases/files of an ID are pooled (window-count weighted mean) into one row; tasks differ between protocols 1.1 and 1.2 and are not separated (disclosed). Every feature is z-scored with training-row mean/std computed separately per device; no label is used.

Baselines (DEV-only selection by DEV CV): B1 age+sex logistic regression (metadata); B2 channel-mean of the five band log relative powers, logistic C=1; B3 Random Forest (300 trees, min_samples_leaf 2, seed 184) on the BP features (the published ASZED baseline family is Random Forest on spectral features). Strongest = highest DEV CV metric. A device-only baseline is by construction 0.5 on the primary metric and is reported on the pooled metric as a confound check.

Published baseline (named; context, not a comparator): Deep Learning Versus Classical Machine Learning for Schizophrenia Detection from EEG: A Cross-Dataset Generalization Study, preprint https://www.preprints.org/manuscript/202601.0860 (abstract at https://sciety.org/articles/activity/10.20944/preprints202601.0860.v1): on ASZED-153 with subject-level stratified CV, EEGNet 70.7% and Random Forest on spectral features 66.8% accuracy, external Kaggle EEG 54.6%/45.4%. Different protocol, accuracy not AUC, preprint not peer-reviewed, device control not stated; no validated published AUC baseline on this dataset was found. Dataset paper: "An open-access EEG dataset from indigenous African populations for schizophrenia research" (Mosaku et al.). Not re-implemented.

New method (candidate grid, 6 members): logistic regression L2, feature set in {BP, BP+SP} x C in {0.01, 0.1, 1}. Selected = highest DEV CV metric (ties: list order).

Primary metric: macro within-device AUC = mean of the AUC among CONTEK IDs and the AUC among DISCOVERY IDs. DEV CV: 5-fold stratified by device x label, 3 repeats (seeds 184+rep), metric = mean over folds (fold-device AUCs averaged per fold, undefined ones skipped; per-fold values printed) then over repeats. Per-fold-averaged AUC is used because pooled out-of-fold AUC showed a negative null bias in the pre-lock smoke (about 0.46-0.49) while per-fold averaging was unbiased.

Headroom (DEV only): drop if strongest-baseline DEV metric >= 0.94 (within 2x the 0.03 WIN threshold of ceiling 1.0) or < 0.55 (no skill). TEST is opened only if the headroom gate and the PERM gate pass; otherwise the unit is reported as a DEV-gate drop.

PERM gate (covers EVERY grid member and every baseline, not only the selected pair): 60 permutations of labels within device on DEV, the full CV pipeline per member; pass iff each member mean metric is within 0.5 +/- 0.03. TEST-side smoke: DEV and TEST labels both shuffled within device, fit on shuffled DEV, score shuffled TEST, 60 permutations, every member, pass iff within 0.5 +/- 0.04. Pre-lock smoke result (same run.py): DEV means 0.482-0.509, TEST means 0.488-0.506 for all 9 members, gate PASS. An earlier smoke with the pooled out-of-fold metric failed (mean 0.46-0.49); the metric was changed to the per-fold average before lock (pre-lock design change, disclosed).

Metric+CI on TEST: selected model and the DEV-strongest baseline are trained on all DEV IDs (device z-scoring from DEV), scored on TEST. Gain = macro within-device AUC(selected) - AUC(baseline). CI: ID-cluster bootstrap resampling IDs within device x label strata (paired between the two models), 2000 reps, seed 184, percentile 95%. WIN: gain >= 0.03 and CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. No re-banding.

Sensitivity (DEV only, reported not gating): S1 leave-device-structure transfer: train on all DEV IDs of one device, score the other device's DEV IDs, both directions (AUC); pooled (device-confounded) OOF AUC of the selected model next to the device-only score AUC.

Power note (cluster-aware, label-free; derived with counts only, not outcomes): 153 independent units (IDs), median 12 EDF files per ID add no independent units (features are collapsed to one row per ID); 21 IDs appear in two subsets and are single clusters. Because the metric is within device, the effective TEST sizes are CONTEK 25P/13C and DISCOVERY 11P/27C. Hanley-McNeil macro SE about 0.07 at AUC 0.65-0.75 (95% half-width about 0.13), paired-difference SE about 0.08, minimum detectable gain at 80% power about 0.23, far above the 0.03 WIN threshold: a NULL means "not decidable at this size", and a WIN at 0.03 would be possible only through a lucky bootstrap, not a powered test.
