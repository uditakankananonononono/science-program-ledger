# U185 PREREG - ASEEG (Zenodo 18029536) resting EEG, schizophrenia vs healthy control, person-level: spectral+coherence LOCAL vs strongest DEV-tuned spectral baseline, with mandatory sex+age+length comparator
Surface + license: ASEEG, Zenodo 18029536, resting EEG, schizophrenia (SZ) vs healthy control (HC), private clinic Tehran. CC BY 4.0 per Zenodo API and paper data statement (no root licence file). PREPROCESSED source, documented chain: 500->128 Hz, 1-45 Hz 4th-order Butterworth, 50 Hz notch, EEGLAB; paper claims no ICA/ASR/interpolation and no re-reference; sampling rate is not stored in the files (128 Hz taken from the publication, not inferred). NOT a native-raw admission; no raw reconstruction; the paper's alternative ASR/FIR description is not applied. EO.rar (259,905,941 B, MD5 019f81936e8272c339285540239a5f12) and EC.rar (269,461,049 B, MD5 327f855a27593985f35e8a4a1643a2fc) were fetched from the Zenodo API URL by this builder and both MD5s match; 198 MAT v7.3 files, variable preprocessed_data, samples x channels, 19 channels. No channel labels are stored; channel order is unverified, so no regional or topographic grouping is used and no topographic claim is made.
Task + labels: person-level SZ (1) vs HC (0). Units are 101 class-qualified people (51 SZ sz1-sz51, 50 HC n1-n50; IDs restart per class so IDs are always class-qualified, e.g. HC_n3, SZ_sz3). EC exists for 101, EO for 97 (SZ 4/15/18/19 EC-only). A person's EO and EC always stay together in one split. Age and sex come from the publisher workbook (Sheet1 = SZ 51 rows, Sheet2 = HC 50 rows; numeric IDs match file IDs). DSM-5 SZ diagnosis is publisher-grounded only. Not pooled with ASZED (unit 184).
Exclusions: none (no rule-based exclusion; all 101 people kept). Carried publication conflicts, not repaired: (a) paper validation section mentions ASR/FIR, contradicting the no-ASR release pipeline; (b) 193/198 arrays are 38400 samples, 5 shorter (EC sz15 33152; EO sz16 38272, sz9 37888, sz13 38272, sz38 38144) vs paper "all 300 s, no segments deleted"; no padding or trimming, length is a confound and is in the mandatory comparator; (c) actual SZ ages 15-74 (37M/14F) and HC 18-52 (17M/33F) vs paper 15-65 and "demographically matched" (the paper text also says 15 SZ females, the workbook has 14). Also: array means are not zero for a stated 1-45 Hz band-pass; not investigated.
Split: sort the 101 class-qualified people by (class HC before SZ, numeric ID); 0-indexed position even = DEV (51 people: 25 HC, 26 SZ), odd = TEST (50: 25 HC, 25 SZ). Never split inside a person. TEST features are extracted label-free before lock only to run the shuffled-label PERM smoke; no real TEST label is used in any model fit, selection or score before lock. Counts-only table (label x sex, age band, EC/EO availability, array length; all, DEV, TEST) is published in counts.json before modelling. DEV: HC 16f/9m, SZ 8f/18m; TEST: HC 17f/8m, SZ 6f/19m. The sex imbalance is large in both splits.
Features (per recording, Welch-style STFT 256 samples / 50% overlap / Hann / constant detrend, assuming 128 Hz): per channel log10 absolute power in delta 1-4, theta 4-8, alpha 8-13, beta 13-30, gamma 30-45 Hz (ABS, 95 features); relative band power (REL, log10, 95); magnitude-squared coherence per channel pair and band (171 pairs x 5 = 855, Fisher-transformed sqrt) used only inside LOCAL. Primary model uses EC recordings (all 101). EO is secondary and descriptive (97 people). Coherence is not corrected for volume conduction or common reference.
Baselines (DEV-tuned only): standardise + L2 logistic regression, class-balanced, C in {0.003, 0.01, 0.03, 0.1, 0.3, 1} chosen by DEV 5-fold stratified person-level CV AUROC (5 repeats, seeds 185+r). B1 family (strongest standalone, cost-matched, same learner): ABS, REL, ABSREL; headline B1 = best DEV-CV member. MANDATORY comparator DEMO: sex, age, EC array length, EO array length (EC length where EO absent) only. DEV selected: B1 = ABS C=0.003, DEMO C=1, LOCAL C=0.003. Both selected C values (B1, LOCAL) sit at the lower grid edge (disclosed grid edge; grid not extended).
New method LOCAL: REL log power + Fisher coherence (95 + 855 = 950 features), same learner, C chosen on DEV CV.
Headroom (DEV only, computed before lock): strongest standalone baseline DEV CV AUROC 0.8243 (ABS C=0.003; DEMO best 0.707, REL best 0.814, ABSREL best 0.818, LOCAL best 0.803); headroom to ceiling 1.0 = 0.176 > 2x WIN threshold (0.06); skill present (>= 0.60, bootstrap lower 0.697 > 0.5). Gate PASS. DEV subject-bootstrap CI for LOCAL-B1 is [-0.077, +0.035] and for B1-DEMO [-0.038, +0.243]; DEV sex-stratified and age-matched AUROCs of B1 are 0.81 and 0.78 vs DEMO 0.57 and 0.48. No published person-level comparator is claimed: the dataset paper text reports no classification result that I found, and a web search found none specific to ASEEG; absent as far as checked.
Metric + CI: TEST person-level AUROC. Subject bootstrap stratified by class x sex, 2000 reps, seed 185, paired differences. WIN threshold = 0.03 AUROC (house). Raw gain gates: LOCAL-B1 >= 0.03 with CI lower > 0, AND LOCAL-DEMO >= 0.03 with CI lower > 0. WIN additionally requires confound robustness on TEST: sex-stratified mean AUROC (mean of male and female AUROC) bootstrap CI lower > 0.5, age-matched subsample AUROC (within-sex greedy 1:1 nearest-age match, caliper 5 years, deterministic by ID) CI lower > 0.5, and demographic-residualised LOCAL (features regressed on sex, age, EC and EO length using DEV only) AUROC CI lower > 0.5. If raw gain gates pass and robustness fails: CONFOUND-FAIL, not a WIN. NEGATIVE: LOCAL-B1 CI upper < 0. Else NULL. No re-banding. Also reported: B1 vs DEMO, AUROC by sex, AUROC in the EO-available subset, scores of the 2 EC-only TEST SZ, EO-model AUROC (descriptive, not gated).
Power note (label-free): 50 TEST people (25/25), 25 female/25 male; AUROC standard error around 0.07, and the shuffled-label spread of the LOCAL-B1 TEST gain is SD 0.091 (20 shuffles), so the minimum detectable gain is roughly 0.2 AUROC, far above the 0.03 threshold. A NULL will mean "not decidable at this size". The matched and sex-stratified subsets are smaller still. Effective sample is 101 people, one site, with selection uncertainty not in the intervals.
PERM smoke (before lock): 20 global label shuffles within DEV and within TEST separately; every grid member (30: DEMO 6, ABS 6, REL 6, ABSREL 6, LOCAL 6) is scored, DEV-CV (1 repeat) and DEV-fit/TEST AUROC. Rule fixed in run.py: every member's mean over shuffles must lie in [0.40, 0.60] (DEV CV) and [0.45, 0.55] (TEST). Result PASS: DEV-CV means 0.43-0.52 (CV on tiny n biases below 0.5), TEST means 0.47-0.52; the perm LOCAL-B1 gain mean is -0.015. perm=false is the real unpermuted run.
Scope: PARTIAL, one private clinic, preprocessed data, 101 people, sex strongly imbalanced between classes, medication and illness duration unknown to this analysis. Classical only. No clinical or diagnostic claim. Not pooled with ASZED. Second looks: the DEV stage (CV, bootstrap) ran once before lock; TEST is read once after lock; any further look will be disclosed. Seeds fixed; logistic regression is deterministic.
