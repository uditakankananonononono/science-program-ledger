# P98 preregistration (locked before any counting)
Data: BBBC005 (Broad Bioimage Benchmark Collection, CC0 per original page): images zip sha256 9ab5e7e1d544f5b88f43b6fc8c2236ff63a0659c9ba17b850d43f290d80c6815 (matches scout); ground-truth zip sha256 40edbd48e0c28e9adeb000893888c7291b28c788d1093bda7b5999753795a514. 9,600 w1 images (synthetic cells, 24 counts C, 16 focus levels F, 8 sites s); true count = the C number in the filename (scout-verified encoding). The ground-truth zip is used only to sanity-check the C-encoding on 20 images (not scored).
Split (frozen by filename rule): sort w1 files; well name (e.g. B13) parsed; DEV = wells whose column number <= 12, TEST = wells whose column number >= 13 (disjoint wells). DEV subset = 600 random DEV images (RandomState(0)); TEST subset = 1,200 random TEST images (RandomState(1)). Touched once.
Baseline B (scikit-image): Gaussian smoothing sigma s, Otsu threshold, distance-transform peak-local-max watershed (min_distance m); count = number of labels. Grid (DEV): s in {0,1,2}, m in {3,5,7}; choose min DEV MAE (ties smaller s, then smaller m). Grid edges declared.
New method ASB (adaptive-scale blob counter): estimate per-image blur b = 1/(variance of Laplacian of the Gaussian(1)-smoothed image) normalised by the DEV median (b<1 sharper, >1 blurrier); LoG blob detection (skimage.feature.blob_log) on the min-max normalised image with sigmas from smin to smax where smin=a*sqrt(b)... precisely: sigma set = linspace(2,8,7) scaled by (1+k*(b-1)) with k in {0,0.25,0.5}; threshold th in {0.02,0.04,0.08}; overlap 0.5; count = number of blobs. Choose (k,th) on DEV min MAE (ties smaller k, then smaller th). k=0 is the non-adaptive control.
Metric (primary): TEST mean absolute count error (MAE); paired bootstrap over TEST images (10000, seed 7) of |err_B| - |err_ASB|; report relative MAE reduction. WIN: relative MAE reduction >= 10% with CI lower of the paired difference > 0. NEGATIVE: CI upper < 0. Else NULL. Secondary: MAE per focus group (F<=10, 11-30, 31-48 bins as given by the F number) and the k=0 control on TEST.
Equivalence check: counting a synthetic image of 5 isolated discs must give 5 with both counters (assert).
Disclosure: synthetic images only; the C number is the reference count by dataset design; one dataset; images in TEST share sites with DEV but not wells.
