DATA SCOPE: NTT (ATP/ADP antiporter) PROTEIN alignment (not 16S): Figshare doi:10.6084/m9.figshare.1104386.v1, CC BY 4.0, archive sha256 720d568e3d9b86a0f3fe065a3758b686bd9f68096c118273cda17069d13eff81 (publisher MD5 matched by scout), files ntt_sequences_trimal_automated1.phy (interleaved PHYLIP, 89 taxa x 437 columns, sha256 f2fa1b07...aea8d0, 63,473 B; the untrimmed fasta in the archive, 750 columns, is NOT used), ntt_c20.tre (sha256 5d24de1c...f95a62, 3,877 B). 89 taxa; the REFERENCE TREE IS A PUBLISHED INFERRED (PhyloBayes C20) TREE, NOT KNOWN TRUTH. Metric = concordance with that inferred tree, so no topology-accuracy claims. run.py verifies the archive hash and member hashes (full hashes in files list inside run.py).
Design: columns of the aligned fasta (all columns, gaps kept) randomly permuted (seed 11) and split: DEV columns (first half) and TEST columns (rest). A replicate = random 40-taxon subset (without replacement) + bootstrap resample (with replacement) of columns to the half's length from that half. DEV: 100 replicates (seed 21); TEST: 300 replicates (seed 22), run once. Replicates share taxa/columns so are NOT independent (disclosed; CI is optimistic).
Pairwise distance: over columns where both sequences have a residue; p = mismatch fraction, capped at 0.90; pairs with <30 comparable columns get p=0.90.
Baselines (my implementation, equivalence-checked against Biopython DistanceTreeConstructor.nj on random matrices: identical split sets required, else amendment before results): NJ with Poisson d=-ln(1-p) (B1) and NJ with Kimura protein d=-ln(1-p-0.2p^2) (B2). Headline baseline = lower DEV mean nRF of B1,B2.
New method: BIONJ (Gascuel 1997, variance = distance, lambda chosen by the BIONJ formula) on gamma-corrected distances d=a[(1-p)^(-1/a)-1], a in {0.5,1,2,5} chosen on DEV (grid edges 0.5 and 5 declared; edge selection reported; ties -> larger a). Equivalence check: BIONJ and NJ both must recover the true topology from an exactly additive 12-taxon matrix.
Ablations reported (not tested): NJ + gamma(a*), BIONJ + Poisson.
Metric: normalised Robinson-Foulds nRF = |symmetric difference of nontrivial unrooted splits| / (|ref splits pruned to subset| + |estimated splits|) vs the reference tree pruned to the 40 taxa (pruned splits with <2 taxa on either side removed; multifurcations kept as is). Paired per-replicate diff (baseline minus new). 95% CI = bootstrap over TEST replicates (10000, seed 7). WIN: relative nRF reduction >= 5% AND CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. No re-banding.
