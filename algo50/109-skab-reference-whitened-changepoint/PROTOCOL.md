# P109 preregistration (locked before any detection was scored)
Transfer claim (scope rule): SKAB is an industrial valve testbed, not bio/medicine. The transferable question is multivariate changepoint/event detection in multichannel physiological or monitoring signals (ICU vitals, wearable streams) when only a short initial normal period is available per recording. No bio equivalent was verified here; this unit supports no medical claim.
DATA: SKAB (waico/SKAB), pinned commit b2c0d46c2971dcbfe71e26087b6d231998bb91c2, GPLv3 (LICENSE and README preserved; redistribution carries GPL obligations). All 20 pinned experiment files: valve1/0..15.csv and valve2/0..3.csv, 22,472 rows, 79 labelled changepoint samples (scout-verified; per-file sha256 in file-integrity.csv, which run.py checks against the files; the run aborts on any mismatch). 8 sensor channels: Accelerometer1RMS, Accelerometer2RMS, Current, Pressure, Temperature, Thermocouple, Voltage, Volume Flow RateRMS. 'anomaly' and 'changepoint' columns are NEVER model inputs; changepoint is the truth. Each file has 3-4 changepoints. Files are experiments on one testbed, not independent subjects; disclosed.
Split by file: DEV (tuning only) = valve1/0..7; TEST (once) = valve1/8..15 and valve2/0..3 (12 files, 47 events at lock time; valve2 is a different valve setting and is reported separately as descriptive).
Per-file preprocessing (identical for ALL methods): the first 200 rows are treated as the reference (normal) period (a frozen rule that uses no labels; the first labelled event is at row ~560 or later in every file); each channel is centred and scaled by its reference mean and sd (sd floor 1e-6 times global median sd).
Scoring: predicted breakpoints are matched one-to-one to true changepoints within margin M=30 samples (greedy by increasing distance); TP = matched, FP = unmatched predictions, FN = unmatched truths; pooled over TEST files F1 = 2TP/(2TP+FP+FN). Equivalence check (asserted): my TP/FP/FN agree with ruptures.metrics.precision_recall (M=30) on 200 random synthetic cases with well-separated breakpoints (ruptures excludes the terminal breakpoint, so precision*len(pred) and recall*len(true) must equal TP when pred is non-empty). A first draft of this assert was vacuous and was fixed before any detection was scored.
Baselines (ruptures 1.1.10, run on the standardised 8-channel series): PELT-l2 (min_size 20, jump 5, pen in {10,30,100,300,1000}), PELT-rbf (min_size 20, jump 5, pen in {1,3,10,30,100}), Binseg-l2 (min_size 20, jump 5, pen same as PELT-l2 grid), Window-l2 (width in {20,40}, pen in {10,30,100,300}). Headline baseline = highest DEV pooled F1 over all these configs. (The oracle number-of-breakpoints variant is NOT used.)
New method RWE (reference-whitened energy scan): whiten the series with the reference-period covariance (shrinkage: Sigma_ref + 0.1*trace/8*I, Cholesky inverse); statistic s_t = (w/2) * || mean(z[t-w:t]) - mean(z[t:t+w]) ||^2; threshold theta = c * median(s_t over t in the reference period where defined, floored at its 25th percentile >0); peaks = scipy.signal.find_peaks(s, height=theta, distance=w); breakpoints at peak indices; first 200 rows excluded from detection. w in {10,20,30}, c in {5,10,20,40,80,160}; chosen by DEV pooled F1 (ties: larger w, then larger c). Edges declared: w 10/30, c 5/160.
Verdict: paired difference of pooled TEST F1 (RWE minus headline) with 95% CI by bootstrap over TEST files (10000, seed 7; resample files, recompute pooled F1). WIN: diff >= +0.05 and CI lower > 0. NEGATIVE: CI upper < 0. Else NULL. No re-banding. Also reported: precision, recall, per-subset (valve1 vs valve2) pooled F1, and the oracle-K Binseg reference F1 (descriptive).
